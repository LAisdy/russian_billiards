# RULES_DEVIATIONS.md — Deviations from official Russian pyramid rules

Companion log to the Russian pyramid extension of pooltool
(`pooltool/ruleset/russian_pyramid.py`). It records every deliberate or
pragmatic deviation between the implemented rulesets and the official rules of
the Russian Billiards Federation (ФБСР — Федерация бильярдного спорта России),
or an equivalent authoritative source, for each discipline:

| Class                      | Discipline (RU)                      | Common name              |
|:---------------------------|:-------------------------------------|:-------------------------|
| `RussianFreePyramid`       | Свободная пирамида                   | Free Pyramid             |
| `RussianCombinedPyramid`   | Комбинированная (Московская) пирамида | Combined / Moscow Pyramid |
| `RussianDynamicPyramid`    | Динамичная (Невская) пирамида        | Dynamic / Nevskaya Pyramid |
| `RussianClassicPyramid`    | Классическая пирамида                | Classic Pyramid          |

## Policy

1. **No silent deviations.** Any rule that is simplified, approximated, or
   omitted (e.g., referee judgment, physically-declared shots, UI-only
   interactions) must be logged here **before** the corresponding step is
   marked DONE in `PROGRESS.md`.
2. Each entry records: rule area, official rule (summary), implemented
   behavior, and rationale.
3. Simplifications mandated by the task statement (e.g., Free Pyramid's
   simplified «свояк» handling) are also logged here.
4. This file is finalized in Step 12.
